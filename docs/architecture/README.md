# Schémas d'architecture
- `c4-level1-context` : le système, ses utilisateurs et les systèmes externes
- `c4-level2-containers` : applications, bases, services (chaque conteneur avec sa région, sa taille et son mode 24 h/24 ou à la demande)
- `bpmn-procurement` : processus cible
- `uml-*` : cas d'utilisation, modèle de données, séquences

Règles C4 du cours : un titre avec le niveau, une légende, chaque élément avec un nom, un type et une techno, chaque flèche avec un verbe et un protocole, un seul niveau par schéma.
